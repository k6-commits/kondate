## 提案の要約

**仮称「きめとく」― うちの献立当番**

- 献立を「作る」AIではなく、「回す」AI。
- 家族の定番料理を覚えて、買い物日に合わせて平日の夕食と買い物リストを先に決めておく。何もしなければそのまま確定し、予定が崩れたら1タップで組み直す。
- 対象は日本の共働き・子育て世帯。入口はLINE。
- LLMは入力の整理と、検証済みの候補からの選択に使う。アレルゲンの判定と、分量・買い物リストの計算はLLMに任せずコードで行い、判定できない物は「要確認」で止める（安全を保証するものではない）。
